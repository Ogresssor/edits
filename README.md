# Автономная фабрика эдитов по фильмам

Приложение само выбирает фильм, который сейчас в тренде, находит в нём самые захватывающие сцены и делает
из них вертикальные ролики для Shorts с субтитрами и фоновой музыкой. Потом выкладывает их на ваш
YouTube-канал по расписанию.

С каждого фильма получается:
- **3 мини-истории** (до 30 с): у каждой своя тема и законченная мысль — завязка, событие, развязка
  или панчлайн. История собирается из 1–3 кусков одной сюжетной линии, «вода» между ними вырезается.
  Звук фильма главный, музыка тихо играет фоном, внизу субтитры.
- **1 общий эдит** (30 с): нарезка лучших моментов фильма под бит музыки.

Все ролики — на весь экран 9:16. Кадрирование работает как оператор: внутри плана камера стоит
на главном герое, на склейке переставляется, плавная панорама — только если герой уходит далеко.
Результат лежит в `output/<Название фильма>/`.

## Как устроено

```
TrendAgent ──► AnalyzerAgent ──► ResearchAgent ──► CuratorAgent ──► MusicAgent ──► EditorAgent ──► MetadataAgent ──► UploaderAgent
 тренды TMDB    сцены, моменты,   Википедия,        Claude читает     свободная      кадрирование     название,        YouTube API
 + ваша         расшифровка речи  Викицитатник,     карту сюжета      музыка под     9:16, Real-ESRGAN, описание, теги,
 библиотека     (Whisper)         TMDB -> задания   + справку         жанр фильма    субтитры, звук   автор музыки
                                  остальным агентам
```

| Агент | Файл | Что делает |
|---|---|---|
| Тренды | [editbot/agents/trends.py](editbot/agents/trends.py) | Берёт из TMDB тренды и то, что сейчас в кино, сопоставляет с файлами в `library/` и выбирает самый трендовый необработанный фильм |
| Аналитик | [editbot/agents/analyzer.py](editbot/agents/analyzer.py) | Проходит весь фильм: громкость, всплески после тишины, движение в кадре, частота склеек, яркость. Расшифровывает всю речь (Whisper; при нескольких звуковых дорожках выбирает русскую) и собирает **карту сюжета** `work/<фильм>/story.txt` — фильм блоками по 10 с с накалом и репликами. Отмечает сцены-кандидаты и пиковые моменты |
| Исследователь («режиссёр») | [editbot/agents/research.py](editbot/agents/research.py) | Собирает справку о фильме из Википедии (ru/en), Викицитатника и TMDB: сюжет, персонажи и актёры, жанр, известные цитаты. Раздаёт задания: куратору — культовые сцены и граница спойлеров, субтитрам — имена героев, музыке — запросы под жанр, метаданным — актёры и хэштеги. С ключом Claude задания пишет Claude. Кэш — `work/<фильм>/research.json` |
| Куратор | [editbot/agents/curator.py](editbot/agents/curator.py) | Claude читает карту сюжета и справку исследователя и придумывает до 13 эдитов: тема, законченная мысль, подпись, стиль музыки и 8–16 фрагментов по 1–5 с — ключевые реплики героев (с субтитрами) вперемешку с экшеном под музыку, с пометками «замедление» / «speed ramp». Решение — в `work/<фильм>/curation.json`, его можно поправить вручную |
| Музыкант | [editbot/agents/music.py](editbot/agents/music.py) | Ищет на Openverse музыку под настроение: сначала Jamendo и Wikimedia (Kevin MacLeod, Rafael Krux и др.), потом Freesound. Только CC0, CC BY и Public Domain. Скачивает 8 вариантов, выбирает лучший и берёт его самую мощную часть |
| Кадрирование | [editbot/reframe.py](editbot/reframe.py) | Нейросеть YuNet находит лица. Внутри плана окно стоит на главном герое (медиана положения). Всё считается по кадрам исходника, поэтому окно переставляется ровно на кадре склейки. Панорама сдвигает окно на доли пикселя, без ступенек. Режимы `edit.reframe`: smart / static / center |
| Увеличение | [editbot/upscale.py](editbot/upscale.py) | Real-ESRGAN (general-x4v3) на видеокарте через PyTorch: окно ~225×400 из 720p-исходника увеличивается без «мыла». Без CUDA — обычный lanczos. Настройки `edit.upscale`, `edit.upscale_denoise` |
| Субтитры | [editbot/subtitles.py](editbot/subtitles.py) | Whisper + `.srt`. Стиль эдита: Segoe UI Black с обводкой, по 2–3 слова, фраза «выпрыгивает», звучащее слово подсвечивается (караоке). Словарь исправлений `subtitles.fixes` |
| Монтажёр | [editbot/agents/editor.py](editbot/agents/editor.py) | Собирает эдит под бит: каждая склейка ровно в долю трека, экшен-кадры до 2.5 с, реплики не обрываются, ролик до 30 с. Динамика: «удар» наездом на склейке, медленный наезд, тряска и вспышки на сильных долях, slow-mo и speed ramp со смешиванием кадров. Обработка: тил-оранж, свечение, резкость, виньетка, зерно. Звук: музыка главная, реплики героев её приглушают |
| Метаданные | [editbot/agents/metadata.py](editbot/agents/metadata.py) | Название, описание с хэштегами и теги, плюс строка с автором музыки (требование лицензии CC BY) |
| Загрузчик | [editbot/agents/uploader.py](editbot/agents/uploader.py) | Загружает через YouTube Data API с докачкой и повторами. При исчерпании квоты переносит ролики на следующий цикл |

Без ключа Claude сцены выбираются только по громкости и динамике: такой подбор заметно хуже,
потому что красоту, смысл и интригу сцены сигналы не видят.

## Установка (Windows)

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # и впишите ключи
```

ffmpeg, модель поиска лиц и модель распознавания речи скачиваются автоматически при первом запуске
(Whisper small весит ~480 МБ).
Для нейросетевого увеличения нужна видеокарта NVIDIA и PyTorch с CUDA:
`.\.venv\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cu128`.

### Ключи

1. **Claude** — `ANTHROPIC_API_KEY` в `.env` (https://console.anthropic.com). Без него куратор работает на эвристике.
2. **TMDB** — `TMDB_API_KEY` в `.env`, ключ бесплатный: https://www.themoviedb.org/settings/api.
3. **YouTube**:
   1. Откройте https://console.cloud.google.com, создайте проект и включите **YouTube Data API v3**.
   2. В разделе *OAuth consent screen* выберите тип *External* и добавьте свой Google-аккаунт в *Test users*.
   3. В разделе *Credentials* выберите *Create credentials → OAuth client ID → Desktop app*, скачайте JSON
      и сохраните его как `secrets/client_secret.json`.
   4. Выполните один раз `.\.venv\Scripts\python main.py auth`: откроется браузер, войдите в аккаунт канала.

## Использование

### Главное: дал фильм — получил эдиты

```powershell
.\.venv\Scripts\python main.py run --no-upload --movie "library\Фильм.mkv" --count 3
```

Больше ничего не нужно: исследователь найдёт фильм в Википедии, аналитик расшифрует речь, куратор выберет
3 лучшие сюжетные линии (без ключа Claude — автоподбором), монтажёр соберёт эдиты в образе под жанр, уборщик
почистит временные файлы. Ролики — в `output/<фильм>/`. Повторный запуск берёт те же линии из
`work/<фильм>/arcs.json` (его можно поправить руками: реплики, кадры, заголовок); `--fresh` — выбрать заново.
Если ролик не собрался, приложение само повторит его в безопасном режиме (без нейросети).

**Формат эдита `arc`** (по умолчанию, `edit.style: arc`) — по разбору 15 эдитов канала-эталона
(`python tools/analyze_reference.py <папка с роликами>` измеряет склейки, бит, зум, вспышки, цвет):
* кадр 1440×1600 во весь экран, тёмный контрастный «кино»-цвет (бирюзовые тени, тёплая кожа, резкость,
  свечение, виньетка); тёмные куски высветляются автоматически;
* одна сюжетная линия из одного эпизода фильма: 4–5 ключевых реплик по порядку (звучат из фильма), между
  ними перебивки под музыку, к концу кадры короче (разгон);
* субтитры посередине кадра в две строки: мелкая белая с разрядкой + крупная цветная со свечением, слова
  проявляются по одному;
* тонкая белая полоса-плашка сверху с фразой в первые секунды;
* музыка — свободный трек в версии «slowed + reverb» (`music.slowed`, `music.reverb`); перед дропом трека
  музыка на миг стихает, на дропе — вспышка и быстрая нарезка ярких кадров эпизода, в конце — замедление;
* вшитые в картинку субтитры фильма (перевод иностранной речи) находятся и срезаются.

Настройки формата — раздел `arc:` в config.yaml (размер кадра, длина истории и финала, плашка).

**Формат `scene`** (`edit.style: scene`): одна цельная сцена фильма с родными склейками, белая плашка-заголовок над
видео, крупные неоновые субтитры, которые «выпрыгивают» по словам, в конце — быстрая нарезка лучших кадров
этой же сцены под бит с переходами (рывок, зум-размытие, RGB-сдвиг, вспышки, тряска). Видео по центру,
масштаб `edit.zoom_pct` (150 % от «фильм во всю ширину»), сверху и снизу чёрные поля. Логотип канала в углу
(STARZ и т. п.) находится и закрашивается автоматически. Образ (`edit.look`) выбирается по жанру:
energy — экшен/гонки, pop — комедии, soft — драмы, dark — ужасы.

### Остальные команды

```powershell
.\.venv\Scripts\python main.py trends              # что сейчас в тренде и что из этого у вас есть
.\.venv\Scripts\python main.py run --no-upload     # только смонтировать и посмотреть output/<фильм>/
.\.venv\Scripts\python main.py run                 # полный цикл с загрузкой
.\.venv\Scripts\python main.py run --movie "library\Film.mkv" --title "Название"
.\.venv\Scripts\python main.py clean --dry-run   # показать, что можно удалить (кэш музыки, старые ролики, временные файлы)
.\.venv\Scripts\python main.py clean             # удалить; после каждого фильма это делается автоматически (секция cleanup)
.\.venv\Scripts\python main.py daemon              # автономно: новый фильм каждые 12 ч
.\.venv\Scripts\python main.py upload              # догрузить то, что не влезло в квоту
```

Фильмы кладите в `library/` (можно подпапками). Файл `.srt` рядом с фильмом подхватится автоматически.
Чем выше разрешение исходника, тем чётче картинка: из 720×304 вертикальный кадр получается растянутым,
1080p даёт заметно лучший результат.

### Автозапуск без открытого окна

```powershell
schtasks /Create /TN "MovieEdits" /SC DAILY /ST 10:00 /TR "\"$PWD\.venv\Scripts\python.exe\" \"$PWD\main.py\" run"
```

## Настройки

Всё лежит в [config.yaml](config.yaml): длина сцен, число роликов, размер и положение субтитров, громкость
музыки относительно фильма (`music.bed_db_scene`, `music.bed_db_montage`), модель Whisper, приватность и
интервал публикаций.

- `youtube.privacy: private` стоит по умолчанию: ролики загружаются скрытыми, чтобы вы проверили первые.
  Когда результат устроит, поставьте `public`. Тогда при `schedule: true` ролики будут выходить по одному
  раз в `interval_hours`.
- Квота YouTube API — около 6 загрузок в сутки.

## Важно: авторские права

Фрагменты фильмов защищены авторским правом. На YouTube такие ролики часто получают **заявки Content ID**
(монетизация уходит правообладателю, ролик могут заблокировать в части стран), иногда и **страйки**:
три страйка — и канал удаляют.

- Музыку агент берёт только под CC0, CC BY и Public Domain и сам указывает автора в описании.
- Источник фильмов — ваши легальные копии. Приложение не скачивает фильмы из интернета.
