# Ошибки и исправления

| Наблюдение | Решение v2 | Статус |
|---|---|---|
| Orchestrator включал upload по умолчанию; цикл сначала догружал старую очередь | Обработка не имеет сетевого загрузчика | Сделано |
| Одноразовые скрипты, latest.json и manifests расходились | Один SQLite, неизменные каталоги по хэшу | Ядро сделано |
| Отбор по динамике/коротким участкам давал странные вставки | Полная карта и описание самостоятельной истории | Карта и валидация сделаны, смысловой разбор ручной |
| AE зависал; старый файл мог выглядеть новым результатом | Новый временный экспорт, код завершения, длительность, receipt SHA; FFmpeg | Сделано |
| Одна музыка на партию | Явная подложка в плане, происхождение и ducking; выбор после прослушивания | Сделано, автоматический выбор отключён |
| Повторные версии одной сцены | Согласование конкретного экспорта, уникальный исходник+интервалы | Точные дубли защищены; смысловые проверяются вручную |
| Очередь на сервере расходилась с локальным планом | Живая сверка перед каждой будущей записью | Требование; загрузчик не перенесён |
| Почти нулевые показы объявлялись проблемой темы без аналитики | Отдельно проверять доступность, показы, свайпы, удержание | Методика; данных для диагноза недостаточно |
| ASR/листы кадров выдавались за просмотр | Явно указывать метод; отдельное подтверждение полного просмотра и прослушивания | Сделано |

Исправления уменьшают ошибки производства, но не доказывают причину низких показов и не гарантируют охваты.
