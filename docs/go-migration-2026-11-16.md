# Переход на Go, 16 ноября 2026

По прямому поручению пользователя перенесено локальное ядро Python → Go. Python-прототип, включая незавершённую анимацию предыдущего шага, сохранён в ветке archive/python-core-2026-11-16, коммит 944ab23ce11a36753c2e17bb47ef61a6d761d773. До удаления файлов проверено совпадение удалённой ветки с локальным коммитом.

Перенесены: регистрация исходника, кэш хэша, техническая карта всего исходника, JSON-планы, четыре профиля, появление слов по таймингам, ограниченные приближения/фокус, рендер, QA, согласование, уникальная локальная очередь, блокировки. Добавлены типизированная валидация, ограниченный batch-пул, отмена FFmpeg и встроенные шрифты.

SDK Go 1.27.4 скачан с официального сайта и проверен по SHA-256. Python не вызывается приложением. FFmpeg скопирован отдельно в `.local/bin`; приложение не зависит от imageio-ffmpeg или .venv. Запускаемый `edits.exe` собирается без сторонних Go-модулей/CGO. Для тестовой озвучки на Windows используется системный TTS через PowerShell, только для демонстрации.

Финальный локальный прогон уже после удаления .venv: `go test -count=1 -json ./...` с EDITS_INTEGRATION=1 — 36 успешных тестов/подтестов, 0 ошибок, 0 пропущенных тестов. Реальные FFmpeg-проверки включают появление текста, приближение, фокус, повторное использование кэша, отклонение чёрного, беззвучного и повреждённого экспорта. `go vet ./...` и Windows-сборка завершились успешно. Лог: `.local/go-validation/tests.jsonl`, сводка: summary.json рядом. Это локальные проверки, не результат GitHub Actions. Race detector локально на Windows не запускался; предусмотрен в Linux CI.

`edits.exe demo` создал три MP4 и полностью проверил их. Просмотрены отдельные кадры ключевых моментов: появление слов, приближение и фокус. Непрерывное человеческое прослушивание не выполнено. Галерея — `.local/go-motion-demo/index.html`. `batch --jobs 2` проверен на трёх неизменных планах: кэш повторно использован. Собран Linux-бинарник с CGO_ENABLED=0; выполнение Linux-бинарника на Windows не проверялось.

Старое генерируемое Python-окружение удалено после сверки SHA-256 вынесенного FFmpeg. Освобождено дополнительно 5,207 ГиБ. Токены/настройки/серверные ролики не удалялись. Исполняемый файл Windows около 8,9 МБ; для работы рядом нужен FFmpeg, Go SDK нужен только для разработки.

Документ проверки Python от 15 ноября — исторический, не доказательство качества Go-версии. Планы JSON сохранены по смыслу совместимыми, но Python receipt и SQLite автоматически не принимаются/не импортируются. Новый реестр стартует отдельно, без возрождения прежней очереди.

Ограничения: ASR фильма, смысловой анализ, умное кадрирование и GUI не реализованы; не обещаем рост охватов или ускорение самого кодека от смены языка. Новый канал/OAuth/YouTube не подключались. Внешние рамки отклонены пользователем; понравившийся второй стиль текста сохраняется.
